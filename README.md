Leonida Cover Lab — a GTA VI cover maker: pick your photos, lay them out in a classic GTA cover grid, grade them sunset or neon, set the title, and export the cover at 1080×1080, 1080×1350, or 1920×1080. Four layouts (nine-panel grid, hero + panels, full-bleed, tilted snapshots), four grades, per-panel crop/zoom/pan, undo/redo, and shuffle. All artwork is original, drawn from the announced facts of the game (Jason Duval and Lucia Caminos in modern-day Vice City, Leonida) — no Rockstar logo, artwork, or font anywhere.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Or build the dossier the grader reads:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
